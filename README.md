# House Price Prediction

## Project Overview

This project predicts house prices using machine learning techniques. Two regression models, Linear Regression and Random Forest Regressor, were trained and evaluated using the Housing Prices dataset from Kaggle.

## Dataset

- Source: Kaggle Housing Prices Dataset
- Total Records: 545
- Features: 13

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Machine Learning Models

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results

Linear Regression performed better than Random Forest on this dataset, achieving an R² Score of approximately 0.653.
